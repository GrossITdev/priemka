# «Приёмка техники» — приложение Битрикс24

Три шага по порядку:

1. **VIN** — сотрудник набирает последние 6 цифр VIN, программа предлагает машины из каталога;
   под каждой — склады, где она стоит (положительный остаток, вкладка «Склады» товара).
2. **6 фото камерой** (не из галереи): спереди, сзади, слева, справа, VIN-номер (шильдик),
   приборная панель заведённого автомобиля. После снимка — миниатюра.
3. **Дефекты автомобиля** — текстом или голосом.

Следующий шаг закрыт, пока не заполнен предыдущий. **«Отправить» — заглушка**: проверяет,
что всё заполнено, и ничего никуда не отправляет.

Устроено как «Перегон техники»: работает через ядро портала, вебхук не нужен, оформление то же.

## Файлы

`index.php`, `install.php`, `lib.php`, `app.js`, `style.css` — в `/local/tools/priemka/`
(на сервере `/home/bitrix/www/local/tools/priemka/`). Подпапок нет. `README.md` класть не нужно.

## Установка

Приложения → Разработчикам → Другое → Локальное приложение:

| Поле | Значение |
|---|---|
| Название / пункт меню | Приёмка техники |
| «Использует только API» | **снять** |
| «Поддерживает BitrixMobile» | отметить — тогда программа есть в мобильном Битрикс24 |
| Путь вашего обработчика | `http://test-portal.gkgross.ru/local/tools/priemka/index.php` |
| Путь для первоначальной установки | `http://test-portal.gkgross.ru/local/tools/priemka/install.php` |
| Права | ничего; если форма не сохраняется — `user` |
| Доступно только администраторам | **не включать** |

Затем открыть приложение → вкладка **«Проверка»** (всё зелёное, пробный поиск по VIN) → **«Доступ»** — выдать сотрудникам.
Администраторы портала входят всегда.

## Адрес тестового портала

Актуальный адрес — `http://test-portal.gkgross.ru/`. Открывать портал и указывать обработчик
и установщик приложения нужно на этом домене, как в таблице выше. Если приложение уже установлено,
исправить оба адреса в его настройках. Переустанавливать приложение не нужно.

Программа работает на адресе, на котором её открыли. Автоматическое переключение домена удалено:
за прокси оно могло отправлять браузер на тот же адрес снова и снова.

## Мобильный Битрикс24

* В настройках приложения отметить **«Поддерживает BitrixMobile»** и заполнить «Название пункта меню».
* В браузере на ПК программа узнаёт сотрудника по сессии портала. Мобильный Битрикс24 может открыть
  программу без этой сессии — тогда она узнаёт сотрудника по ключу входа (`AUTH_ID`), который портал
  передаёт программе при каждом открытии. Ключ проверяет сам портал (модуль `rest`), и выдан он должен
  быть именно этой программе. Дальше страница ходит к программе со своим пропуском на 12 часов.
  Доступ всё так же проверяется на каждом запросе.
* **http или https.** Адрес обработчика должен быть на том же протоколе и домене, по которому телефон
  подключён к порталу. Если мобильный Битрикс24 подключён по https, а обработчик на http — окно программы
  будет белым: телефон не показывает страницу http внутри https. iPhone может не открыть http совсем.
  На тестовом портале (http) телефон должен быть подключён тоже по http.
* Вкладка «Проверка» → «Мобильный Битрикс24» показывает, отмечен ли флажок и на каком адресе обработчик.
* Вкладка «Проверка» → «Последние открытия программы»: кто открывал, с телефона или ПК, по http или https
  и чем кончился вход. На телефоне белый экран, а строки «мобильный Битрикс24» нет — запрос телефона
  до программы не дошёл (чаще всего http внутри https).
* Не получилось войти — программа пишет причину на экране (ключ отклонён, ключ от другого приложения,
  сотрудник отключён). Этот текст нужен тому, кто чинит.

## Где искать технику

По умолчанию — как в «Перегоне»: инфоблок каталога 15, папки 391 и 466 с вложенными, только активные товары.
VIN — в «Названии» и строковых свойствах со словом VIN. Меняется во вкладке «Проверка» → «Настройки поиска»
(хранится в `b_option`, модуль `gross.priemka`). Первыми в списке — машины, у которых VIN кончается набранными цифрами.
Поле VIN принимает только цифры, в том числе при вставке текста. Клавиатура на телефоне — цифровая.

## Фото

* Поле открывает камеру (`capture`). Если телефон всё же дал выбрать файл — файл старше 10 минут не принимается
  («Фото из галереи не принимается»).
* Фото уменьшается в браузере до 1920 точек (JPEG), миниатюра — 360 точек.
* Фото и текст живут в браузере (IndexedDB и localStorage): если телефон перезагрузит страницу,
  пока открыта камера, приёмка не потеряется. Смена VIN всё сбрасывает.

## Голос

* **https** (боевой `portal.gkgross.ru`): кнопка «Записать голосом» пишет речь прямо в программе
  (Chrome, Safari, Edge) и вставляет текст в поле.
* **http** (тестовый `test-portal.gkgross.ru`): браузеры не дают сайтам на http доступ к микрофону, обойти это нельзя.
  Кнопка «Надиктовать» ставит курсор в поле и подсказывает диктовку клавиатуры: значок 🎤 на клавиатуре
  телефона (Gboard, iPhone), на ПК — Win + H. Клавиатура набирает речь текстом на любом адресе, бесплатно.
* Если в браузере нет записи (Firefox, встроенный браузер приложения) — так же, через диктовку клавиатуры.
